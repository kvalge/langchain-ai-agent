### 1. Summary
The team discussed Q2 personal loan default trends (currently 2.3% above forecast) and necessary data fixes ahead of Friday's compliance review. The PostgreSQL ETL pipeline migration is mostly complete, but missing March transaction records need urgent investigation. To prepare for upcoming reporting, the team agreed to prioritize currency standardization across regional branches, clean up dashboard test data, address high false-positive rates in fraud detection alerts, and complete historical data migration over the next two sprints.

---

### 2. Key Discussion Points
* **Loan Default Trends & Compliance:** Default rates for Q1 personal loans are 2.3% above forecast. Corrected datasets are required before Friday’s Risk compliance review.
* **ETL Migration & Missing March Data:** PostgreSQL pipeline migration is mostly finished, but missing March transaction records are blocking the monthly reconciliation report. It is undetermined whether the cause is a new ingestion job issue or a source system outage.
* **Mixed Currency Formatting:** Regional branches are logging currency in varied formats, which will block accurate Q3 reporting unless standardized.
* **Fraud Detection False Positives:** Branch managers reported excessive false alarms from the new fraud scoring model. Threshold adjustments discussed weeks ago were never implemented.
* **Catalog Access & Historical Migration:** Documentation of new tables requires updated data catalog permissions. Migration of historical data (2019–2023) is scheduled for the upcoming sprints.

---

### 3. Decisions
* **Prioritize Currency Normalization:** Agreed by Risk and Analytics to standardize currency formats before Q3 reporting, handling normalization automatically at the ETL layer.
* **Dashboard Filter Adjustment:** Filter out flagged test accounts to remove noise from default rate calculations.
* **Historical Data Migration Timeline:** Target completion of the 2019–2023 historical data migration within two sprints.
