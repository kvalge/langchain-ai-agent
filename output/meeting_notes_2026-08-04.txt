### Executive Summary
The meeting focused on data warehouse migration updates, data quality issues (specifically missing March transactions and mixed currency formats), default rate trends, fraud detection alert adjustments, and compliance alignment. ### Key Discussion Points
1. **Loan Default Trends & Data Quality:**  
   * Anu provided an update on Q2 loan default trends, noting an increase in default rates for personal loans issued in Q1.  
   * Flagged test accounts currently affect the default rate calculations and need filtering.

2. **ETL Pipeline & Historical Migration:**  
   * Mart updated the team on the ETL pipeline migration to the new PostgreSQL warehouse.  
   * Historical data migration (2019–2023) is estimated to take two sprints.  
   * Liisa raised concerns regarding missing March transaction records affecting reconciliation reports. The cause (ingestion job vs. source system outage) is under investigation.

3. **Credit Risk Model & Data Retention:**  
   * The team discussed customer segmentation for the upcoming credit risk model, with Anu proposing adding "income bracket" as a variable.  
   * Discussion held on updating data retention policies per revised compliance guidelines.

4. **Currency Field Standardization:**  
   * Kati highlighted that regional branches still log currency values in mixed formats.

5. **Fraud Detection Model Feedback:**  
   * Branch managers reported excessive false positives with the current fraud scoring model. The team discussed adjusting model thresholds to reduce false positives without missing detections.

* **Default Rate Calculation:** Dashboard filters will be updated to exclude flagged test accounts.
* **Weekly Focus:** Top priorities for the week are the missing transaction investigation, automated currency normalization proposal, and fraud model threshold review.
